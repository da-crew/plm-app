# port-logistics

to run front end:     
cd plm-app    
npm run dev    

to run backend:    
download XAMPP    
start Apache    
start MySQL    
create database name port_logistics    
cd plm-server    
mvn spring-boot:run    

username and password in \plm-server\src\main\java\com\studentgroup\app\webservices\DatabaseInitializer.java
